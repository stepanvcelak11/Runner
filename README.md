# CHRONO-SPIRE

3D mobilní endless runner s mechanikou **inverze času** (v inverzi běžíš pozpátku v čase). Ovládání jako Subway Surfers, vlastní realistická grafika.

**Hrát:** https://stepanvcelak11.github.io/Runner/

- Pohyb: tažení prstem / ←→ / A D
- Skok: tlačítko / švih nahoru / mezerník
- Inverze času: velké tlačítko / Shift / E
